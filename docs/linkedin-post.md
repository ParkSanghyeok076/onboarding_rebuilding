# LinkedIn 포스팅 초안

---

개발자가 아닌 HR 담당자로서 온보딩 시스템을 직접 만들었습니다.

기획, 개발, 배포까지 AI와 함께 진행했습니다.

동기는 단순했습니다. 신규입사자 온보딩을 관리하는 시간이 너무 많이 걸렸고, 데이터가 없으니 무엇이 잘 되고 있는지도 알 수 없었습니다.

React + Supabase + Claude API로 구축한 시스템의 주요 기능입니다.

신규입사자는 사번으로 로그인해 공지사항을 확인하고, 온보딩 6개 활동을 수행한 뒤 이미지로 제출하며, 차수별 설문조사에 참여합니다.

HR 어드민은 CSV 한 장으로 직원을 일괄 등록하고, 활동 제출 현황을 실시간으로 파악하며, 설문 응답을 Claude API가 감성 분석(ABSA)해 멘토·팀장 대상 이메일 초안을 자동 생성합니다.

마지막 기능이 가장 의미 있습니다.

"설문 결과를 보내드립니다"가 아니라, 분석 내용을 커피챗 제안이나 면담 가이드처럼 자연스럽게 녹여낸 초안이 만들어집니다. 신규입사자를 직접 언급하지 않아도, HR의 개입이 보이지 않는 방식으로 전달됩니다.

기대 효과는 두 가지입니다.
신규입사자 적응 상태를 데이터로 파악할 수 있고, HR 후속 조치 시간을 대폭 줄일 수 있습니다.

개발자 없이 만든 HR 시스템이라는 점이 오히려 강점이었습니다. 현장을 알기 때문에 설계가 달라졌으니까요.

AI가 바꾸고 있는 건 개발 방식만이 아닌 것 같습니다.
