# 신규입사자 온보딩 관리 시스템

## 1. 배경

### 1) HR의 온보딩 과정 모니터링 공백

신규입사자의 OJT·멘토링이 시작되면 그 진행 전반이 현업에 일임된다. HR 입장에서는 멘토링이 실제로 이루어지고 있는지, 신규입사자가 조직에 잘 적응하고 있는지를 파악할 공식적인 채널이 없었다. 문제를 조기에 감지하거나 개입할 수 없는 구조인 셈이다.

이 과정에서 발생하는 단절은 단순한 불편을 넘어, 조기 이탈로 이어질 수 있는 리스크다.

### 2) 데이터 분산으로 인한 관리 비효율

기존에는 버디 프로그램 사진, 설문 결과, 온보딩 완료 여부 등의 데이터가 yCloud 여러 폴더에 분산 저장되었다. 관리자는 필요할 때마다 각 폴더를 직접 열어 데이터를 수집·취합해야 했고, 전체 현황을 한눈에 파악하기가 어려웠다.

---

## 2. 주요 기능

### 1) 로그인 및 비밀번호 변경

사번을 기반으로 초기 계정이 자동 발급된다. 초기 비밀번호는 `y{사번}` 형식이며, 최초 로그인 후 개인 비밀번호로 변경할 수 있다. 별도 가입 절차 없이 HR 관리자가 CSV 파일 한 번 업로드로 전체 신규입사자 계정을 일괄 생성한다.

### 2) 공지사항

신규입사자는 그룹웨어 곳곳에 흩어진 정보를 직접 찾아다녀야 한다는 어려움이 있다. 이 시스템에서는 입사 초기에 꼭 알아야 할 정보(복무 규정, 사내 규칙, 복지 제도 등)를 한 곳에 모아 제공한다. 관리자는 게시글을 작성하거나 PDF 파일을 첨부할 수 있으며, 중요 공지는 상단 고정이 가능하다.

### 3) 온보딩 프로그램 (버디 프로그램 온라인화)

기존 버디 프로그램은 지원금을 사용한 후 사진을 촬영하고 스캔본을 HR에 회신하는 방식이었다. 이를 온라인 이미지 첨부 방식으로 전환했다. 모바일에서도 사진을 바로 첨부할 수 있어 현장에서의 접근성이 높아졌다.

6가지 활동(멘토와 티타임, 팀원 인사, 구내식당 이용, 주변 맛집 탐방, 협업 부서 인사, 자율활동)의 완료 현황을 관리자 페이지에서 실시간으로 한눈에 확인할 수 있다. 증빙 이미지를 직접 클릭해서 열람하는 것도 가능하다.

### 4) 설문조사 및 감성분석 (핵심 기능)

#### 설문 구성

온보딩 과정 전반을 파악하기 위한 설문을 월 단위로 실시한다. 신입공채는 3차(입사 후 1·2·3개월), 경력공채는 1차만 진행한다.

설문은 **5개 파트, 23개 문항**으로 구성되며, Likert 5점 척도(정량)와 주관식(정성)을 함께 포함한다.

| 파트 | 내용 | 문항 수 |
|------|------|--------|
| Part 1 | OJT 준비 및 멘토링 태도 | 5문항 |
| Part 2 | 업무 지식 및 기술 전수 | 5문항 |
| Part 3 | 실무 지도 및 피드백 | 5문항 |
| Part 4 | 조직 적응 지원 및 소통 | 5문항 |
| Part 5 | 종합 의견 (전체 주관식) | 3문항 |

정량 데이터는 월별 변화를 추적하는 **시계열 분석**에 활용되며, 응답 수치의 변화를 통해 적응 흐름과 고충의 발생 시점을 포착할 수 있다.

#### 속성기반 감성분석 (ABSA)

일반적인 감성분석은 텍스트 전체를 긍정 또는 부정으로만 분류한다. 반면 **ABSA(Aspect-Based Sentiment Analysis)**는 하나의 문장 안에서 언급된 **속성(aspect)별로 감정을 각각 추출**한다. 예를 들어 "멘토가 친절하긴 했는데 업무 설명이 너무 부족했어요"라는 응답은 단순히 '부정'으로 처리되는 게 아니라, '멘토 태도 → 긍정', '업무 전달 방식 → 부정'으로 분리되어 분석된다. 어디서 만족하고 어디서 어려움을 겪는지를 텍스트에서 직접 읽어낼 수 있다.

구현은 7개 주관식 응답을 Claude API에 전달하는 방식으로 이루어진다. Claude가 텍스트에서 속성을 스스로 식별하고, 각 속성에 대한 감정(긍정·약간 긍정·중립·약간 부정·부정), 감정 점수(−1.0~1.0), 신뢰도, 원문 발췌를 JSON 형태로 반환한다. 파트 구분에 얽매이지 않고 실제 내용 기반으로 속성이 추출되기 때문에, 설문 파트명이 아닌 "멘토링 체계성", "팀 소통", "피드백 빈도" 같은 실질적인 개념 단위로 결과가 나온다.

#### 1on1 제안 이메일 자동 생성

분석 결과를 바탕으로 멘토 또는 팀장에게 발송할 이메일 초안을 자동으로 생성한다. 수신자 유형에 따라 톤이 달라진다. 멘토에게는 동료 간 따뜻한 어조로 강점을 언급하면서 개선 제안 1가지를 포함하고, 팀장에게는 업무 보고 형식으로 전체 감성 분포와 조치 필요 항목을 간결하게 요약한다.

이를 통해 HR이 직접 개별 면담을 주도하지 않더라도, 현장 관리자가 적시에 신규입사자에게 개입할 수 있는 체계를 만들 수 있다.

## 3. 기술 구성

| 구분 | 기술 |
|------|------|
| 프론트엔드 | React |
| 백엔드·DB | Supabase (PostgreSQL + Auth + Storage) |
| AI 분석 | Claude API (claude-sonnet-4-6) via Edge Functions |
| 배포 | Vercel (GitHub 연동 자동 배포, HTTPS 자동 적용) |
| 보안 | JWT 인증 + RBAC(역할 기반 접근 제어) + PostgreSQL RLS(행 수준 보안) |

별도 서버 구축 없이 Vercel + Supabase 조합으로 운영되며, 인터넷이 되는 환경이라면 어디서든 웹 브라우저로 접속할 수 있다. 신규입사자는 본인의 데이터에만 접근할 수 있으며, 관리자 기능은 계정 역할을 UI·서버·데이터베이스 세 단계에서 모두 검증하여 권한 없는 접근을 차단한다. Claude API 키는 서버 측 환경변수에만 저장되고 클라이언트에는 전달되지 않아, 외부 AI API를 사용하더라도 키 유출 위험이 없다.

## 4. 기대효과

### 온보딩 고도화
멘토링 준비도, 업무 지식 전달, 조직 적응 등을 체계적으로 측정하고 기록한다. 막연한 인상이 아닌 데이터로 온보딩 품질을 관리할 수 있다.

### 조기 이탈 방지
월별 설문과 감성분석을 통해 신규입사자의 적응 상태를 지속적으로 모니터링한다. 이탈 신호를 조기에 감지하고, 이메일 자동화를 통해 현장 관리자가 빠르게 개입할 수 있다.

### 데이터 기반 HRD
시계열 설문 데이터와 ABSA 결과가 누적되면, 온보딩 프로그램의 효과성을 검증하고 개선 방향을 수립하는 근거 자료로 활용할 수 있다. "감에 의한 판단"에서 "데이터에 의한 의사결정"으로 전환이 가능하다.

### 확장성
현재 온보딩 전용으로 구축된 이 시스템은 추후 다음과 같이 확장될 수 있다.

- **조직문화 Pulse Survey**: 전 직원 대상 정기 감성 측정으로 범위 확대
- **GraphRAG 기반 인사이트**: 축적된 설문 데이터를 지식 그래프로 연결하여 더 깊은 패턴 분석
- **멘토 역량 평가 시스템**: 멘토별 피드백 누적 데이터를 기반으로 한 역량 개발 지원
