## 1. 로그인

### 초기 비밀번호
처음 로그인할 때는 아래 형식의 초기 비밀번호를 사용하세요.

| 항목 | 내용 |
|------|------|
| 아이디 | 사번 (예: `1001001`) |
| 초기 비밀번호 | `y` + 사번 (예: `y1001001`) |

> **첫 로그인 후 반드시 비밀번호를 변경하세요.** (→ [7. 비밀번호 변경](#7-비밀번호-변경))

### 로그인 절차
1. 사번을 아이디 칸에 입력합니다.
2. 초기 비밀번호(`y사번`)를 입력합니다.
3. **로그인** 버튼을 클릭합니다.

## 2. 메인 화면 구성

로그인하면 `[이름]님 환영합니다!` 화면이 나타납니다. 세 가지 메뉴 카드가 있습니다.

| 카드 | 기능 |
|------|------|
| 📢 공지사항 | HR에서 등록한 공지·자료 확인 |
| 📋 멘토링 프로그램 | 6가지 활동 수행 및 사진 제출 |
| 📝 설문조사 | 멘토링 과정 만족도 설문 |

화면 상단의 **헤더**에는 다음 기능이 있습니다.

- **진행 상황 표시**: 멘토링 프로그램 완료 현황 (예: `3/6`)
- **멘토 정보 입력**: 멘토 이름·사번 등록 버튼
- **비밀번호 변경**: 우측 상단 버튼
- **로그아웃**: 우측 상단 버튼

## 3. 공지사항

HR 담당자가 등록한 공지와 첨부 파일(PDF)을 확인할 수 있습니다.

### 사용법
1. 메인 메뉴에서 **공지사항** 카드를 클릭합니다.
2. 목록에서 원하는 공지를 클릭하면 상세 내용이 열립니다.
3. 📌 아이콘이 붙은 항목은 **고정 공지**입니다. 항상 목록 상단에 표시됩니다.
4. 첨부 PDF가 있는 경우 **PDF 보기** 버튼으로 파일을 확인할 수 있습니다.
5. **← 메뉴로 돌아가기** 버튼으로 메인 메뉴로 돌아갑니다.

> 공지사항은 읽기 전용입니다. 직접 작성하거나 수정할 수 없습니다.

## 4. 멘토링 프로그램

총 6가지 활동을 수행하고, 각 활동의 증빙 사진을 업로드해야 합니다.

### 6가지 활동 목록

| 번호 | 활동명 | 증빙 예시 |
|------|--------|-----------|
| 1 | 사무실 안내 / PC 세팅 | 함께 일할 공간을 둘러보는 사진 |
| 2 | 팀원들과 간담회 | 회의 테이블에 모여 있는 사진 (얼굴 노출 X) |
| 3 | 구내식당 함께 이용 | 사원증이 보이는 식사 사진 |
| 4 | OJT 현황 보고 | 팀원들에게 이번달 배운 업무내용을 공유하는 사진 |
| 5 | 협업 부서와 인사 | 사원증이 보이는 커피 사진 |
| 6 | 자율활동 | 기타 조직 적응에 도움이 될만한 활동 사진 |

### 사진 업로드 방법
1. 메인 메뉴에서 **멘토링 프로그램** 카드를 클릭합니다.
2. 원하는 활동 카드를 선택합니다.
3. **사진 업로드** 영역을 클릭하거나 파일을 드래그해 이미지를 첨부합니다.
4. 업로드가 완료되면 해당 활동 카드에 미리보기가 표시됩니다.
5. 사진을 교체하고 싶으면 다시 업로드하면 됩니다 (덮어쓰기 됩니다).

> 사진은 **이미지 파일(JPG, PNG 등)** 만 업로드 가능합니다.
> 한 활동에 한 장의 사진만 등록됩니다.

### 진행 현황 확인
- 헤더에 **`완료 수 / 6`** 형식으로 진행 상황이 표시됩니다.
- 6개 활동을 모두 완료하면 멘토링 프로그램이 마무리됩니다.

## 5. 설문조사

멘토링 과정에 대한 만족도를 평가하는 설문입니다.

### 설문 차수 안내

| 구분 | 차수 |
|------|------|
| 신입 | 1차, 2차, 3차 (총 3회) |
| 경력 | 1차 (총 1회) |

### 설문 기간
- 각 차수별로 지정된 **응답 기간**이 있습니다.
- 응답 기간은 종료일 이후 **7일**까지 연장됩니다.
- 기간 전이거나 기간이 완전히 지난 경우 응답할 수 없습니다.

### 설문 화면 상태 안내

| 상태 | 의미 |
|------|------|
| 참여 가능 | 현재 응답할 수 있음 |
| 기간 전 | 아직 설문 기간이 시작되지 않음 |
| 기간 종료 | 응답 기간이 지남 |
| 제출 완료 | 이미 제출한 설문 |

### 설문 진행 방법
1. 메인 메뉴에서 **설문조사** 카드를 클릭합니다.
2. 차수 목록에서 **참여 가능** 상태의 차수를 선택하고 **시작** 버튼을 클릭합니다.
3. 설문은 **5개 파트**로 구성되어 있습니다.

   | 파트 | 내용 |
   |------|------|
   | Part 1 | OJT 준비 및 멘토링 태도 |
   | Part 2 | 업무 지식 및 기술 전수 |
   | Part 3 | 실무 지도 및 피드백 |
   | Part 4 | 조직 적응 지원 및 소통 |
   | Part 5 | 주관식 종합 의견 |

4. 각 파트마다 **객관식(5점 척도)** 과 **주관식(텍스트)** 문항이 있습니다.
5. 모든 문항을 작성해야 **다음** 버튼이 활성화됩니다.
6. 마지막 파트에서 **제출하기** 버튼을 클릭합니다.
7. 확인 팝업에서 **제출** 을 누르면 최종 저장됩니다.

> 한번 제출하면 수정할 수 없습니다. 신중하게 작성해 주세요.

### 결과 확인
- 제출 완료된 설문은 **결과 보기** 버튼으로 본인의 응답 내역을 다시 확인할 수 있습니다.

## 6. 멘토 정보 입력

멘토의 이름과 사번을 시스템에 등록합니다.

### 입력 방법
1. 화면 상단 헤더에서 **멘토 정보 입력** 버튼을 클릭합니다.
2. 팝업 창이 열리면 다음을 입력합니다.
   - **멘토 이름**: 멘토의 성함
   - **멘토 사번**: 숫자 6자리 사번
3. **저장** 버튼을 클릭합니다.
4. 저장 후에는 헤더에 멘토 이름이 표시됩니다.

> 잘못 입력했을 경우 **초기화** 버튼으로 다시 입력할 수 있습니다.
> 멘토 사번은 숫자 6자리만 입력 가능합니다.

## 7. 비밀번호 변경

### 변경 조건
- 새 비밀번호는 **최소 6자리** 이상이어야 합니다.
- 현재 비밀번호와 동일한 비밀번호는 사용할 수 없습니다.

### 변경 방법
1. 화면 우측 상단 **비밀번호 변경** 버튼을 클릭합니다.
2. 현재 비밀번호를 입력합니다.
3. 새 비밀번호를 입력합니다.
4. 새 비밀번호를 한 번 더 입력(확인)합니다.
5. **변경하기** 버튼을 클릭합니다.

> 비밀번호는 본인만 알 수 있게 안전하게 관리하세요.

## 8. 자주 묻는 질문

**Q. 비밀번호를 잊어버렸어요.**
A. HR 담당자(인사기획팀 박상혁 선임, 내선 1456)에게 문의해 주세요.

**Q. 사진 업로드가 안 돼요.**
A. 파일이 이미지 형식(JPG, PNG 등)인지 확인해 주세요. 문제가 지속되면 HR 담당자에게 문의하세요.

**Q. 설문조사 기간이 지났는데 아직 못 했어요.**
A. 설문 종료일로부터 7일까지는 응답할 수 있습니다. 그 이후라면 HR 담당자에게 문의해 주세요.

**Q. 멘토링 프로그램 사진을 수정하고 싶어요.**
A. 해당 활동 카드에서 사진을 다시 업로드하면 이전 사진이 교체됩니다.

**Q. 시스템 문의는 어디에 하나요?**
A. 화면 하단 `문의: 인사기획팀 박상혁 선임(1456)` 으로 연락해 주세요.
