# 직원 수동 입력 테이블 설계

**날짜**: 2026-03-10
**대상 파일**: `src/pages/AdminUsers.js`, `src/pages/AdminUsers.css`

---

## 목적

CSV 파일 없이도 직원을 등록할 수 있도록, 기존 CSV 업로드 영역 아래에 직접 입력 가능한 스프레드시트형 테이블을 추가한다. 엑셀에서 여러 행을 복사해 붙여넣기(Ctrl+V)하면 자동으로 행이 채워진다.

---

## 레이아웃

```
[ 기존 CSV 업로드 존 ]
─────── 또는 직접 입력 ───────
[ 직접 입력 테이블 (스프레드시트형) ]
  헤더: # | 사번 | 이름 | 부서 | 입사일 | 구분 | ✕
  행: input 셀 × 5 + select(신입/경력) + 삭제 버튼
  하단: [+ 행 추가]  [N명 등록하기]
```

CSV 업로드와 직접 입력은 **동시에 표시** (탭 전환 없음). 단, 두 방식을 동시에 등록 시도하면 별도 처리.

---

## 붙여넣기 동작

- 엑셀 열 순서: `사번 → 이름 → 부서 → 입사일 → 구분` (테이블과 동일)
- 엑셀 복사 시 클립보드 형식: TSV (`\t` 구분, `\n` 줄바꿈)
- 테이블 영역 내 어느 셀에서든 Ctrl+V 시 `paste` 이벤트 감지
- 파싱: 줄 단위로 나눠 탭으로 분리 → 각 행을 `{ employee_id, name, department, hire_date, employee_type }` 객체로 변환
- 기존 행 교체: 붙여넣기 시 기존 입력 행을 덮어쓰고 새 행으로 교체
- 빈 행 자동 1개 유지: 마지막에 항상 빈 행 1개

---

## 유효성 검사 (등록하기 클릭 시)

1. 빈 행(모든 셀 비어있음) 자동 제외
2. 필수 항목: 사번, 이름, 입사일, 구분
3. 입사일 형식: `YYYY-MM-DD`
4. 구분: `신입` 또는 `경력`
5. 중복 사번(같은 입력 내) 불가
- 오류 시 기존 CSV 업로드와 동일한 `au-error` 스타일로 표시

---

## 등록 성공 후

- 테이블 행 초기화 (빈 행 1개만 남김)
- 기존 `result` 상태에 성공/실패 결과 표시 (CSV 등록과 동일한 UI)
