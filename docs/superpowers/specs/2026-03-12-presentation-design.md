## 슬라이드 구성 (7장)

### 슬라이드 1 — 표지
- 제목: 신규입사자 온보딩 관리 시스템
- 부제: 온보딩 과정의 디지털화 및 데이터 기반 관리
- 발표자: 인사기획팀 박상혁 선임

### 슬라이드 2 — 기존 워크플로우 (AS-IS)
단계별 흐름 (화살표 다이어그램):
1. 신규입사자 명단 Excel 관리
2. 버디 프로그램 — 사진 촬영 → 스캔 → 이메일 회신
3. 설문 별도 진행 → 결과 수동 취합
4. 데이터 yCloud 폴더별 분산 저장

### 슬라이드 3 — 문제점
두 가지 핵심 문제:
1. **HR 모니터링 공백**
   - 멘토링·OJT가 현업에 전적으로 일임
   - 진행 여부·적응 상태 파악 채널 없음
   - 문제 조기 감지 및 개입 불가 → 조기 이탈 리스크
2. **데이터 분산으로 인한 관리 비효율**
   - 버디 사진·설문 결과·완료 여부가 폴더별 분산
   - 전체 현황 파악 시 수동 취합 필요
   - 실시간 모니터링 불가

### 슬라이드 4 — 시스템 소개
- 이름: YURA 온보딩 관리 시스템
- 웹 기반, 별도 설치 없이 브라우저 접속
- 신규입사자·관리자(HR) 계정 분리 운영
- 신입공채(3개월·3차 설문) / 경력공채(1개월·1차 설문) 구분 지원

### 슬라이드 5 — 주요 기능 (신규입사자 측)
3가지 기능:
1. **온보딩 프로그램 디지털화**
   - 버디 활동 6가지 모바일 이미지 첨부
   - 진행 타임라인 시각화 (현재 단계 실시간 표시)
2. **설문조사 자동화**
   - 신입 3차·경력 1차, 기간 자동 관리
   - 주관식 + Likert 척도 23문항
3. **AI 감성분석(ABSA) + 이메일 자동 생성**
   - 주관식 응답에서 속성별 감정 자동 추출
   - 멘토·팀장 대상 맞춤 이메일 초안 자동 생성

### 슬라이드 6 — 관리자 대시보드
5가지 기능:
1. **온보딩 현황**
   - KPI 카드 4개: 전체 입사자·완료·이번주 설문마감·마감 임박자
   - 개인별 진행률 프로그레스 바
2. **마감 알림**
   - 마감 임박자 클릭 → 대상자 팝업
   - D-1 이하 빨간색, D-2~3 주황색 강조
3. **멘토/버디 관리**
   - 직원별 멘토·버디 배정 팝업
   - 신입·경력 구분 안내메일 HTML 자동 생성
4. **직원 관리**
   - CSV 일괄 업로드 또는 수기 입력(엑셀 붙여넣기)
   - 등록 즉시 계정 자동 생성
5. **공지사항**
   - 인라인 편집, PDF 첨부·교체
   - 중요 공지 상단 고정

### 슬라이드 7 — Q&A
- 한 줄 요약: "온보딩의 전 과정을 하나의 시스템에서 관리하고, AI로 이탈 리스크를 조기에 감지합니다."
- 감사 인사
