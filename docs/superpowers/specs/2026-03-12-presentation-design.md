## 구현 시 주의사항

1. **화살표**: `slide.shapes.add_shape(13, left, top, width, height)` 사용 (`13` = RIGHT_ARROW autoshape ID). `MSO_SHAPE_TYPE`은 읽기 전용 열거형이므로 `add_shape()` 인자로 사용 불가
2. **줄바꿈**: python-pptx에서 `\n`은 텍스트런 내에서 작동하지 않음. 설명 2줄은 `text_frame`에 `paragraph`를 두 개 추가하는 방식으로 처리
3. **출력 경로**: 경로에 한글·특수문자 포함, Python `str` 타입 그대로 사용 (bytes 변환 금지)
4. **디렉토리 생성**: `os.makedirs(output_dir, exist_ok=True)` 스크립트 내 포함
