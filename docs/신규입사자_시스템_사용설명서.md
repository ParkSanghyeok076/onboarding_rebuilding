## 1. 시스템 접속 및 로그인

**접속 주소:** https://yuraonboardingprogram.vercel.app

### 로그인 방법

| 항목 | 내용 |
|------|------|
| 사번 (아이디) | 본인 사번 (예: 2001001) |
| 초기 비밀번호 | **y + 사번** (예: y2001001) |

> **주의:** 첫 로그인 후 반드시 비밀번호를 변경해 주세요.

---

## 2. 초기 비밀번호 변경

1. 로그인 후 우측 상단 **프로필 버튼** 클릭
2. **비밀번호 변경** 선택
3. 현재 비밀번호(초기: y+사번) 입력
4. 새 비밀번호 입력 후 확인

> 비밀번호를 잊어버린 경우 인사기획팀(1456)으로 문의해 주세요.

---

## 3. 메인 대시보드 안내

로그인 후 메인 화면에서 다음 정보를 한눈에 확인할 수 있습니다.

| 위젯 | 내용 |
|------|------|
| 온보딩 타임라인 | 전체 온보딩 기간 및 현재 진행 위치 |
| 담당 멘토 | 배정된 멘토 이름 및 사번, 등록 요청 버튼 |
| 프로그램 진행률 | 6가지 활동 중 완료한 항목 수 |
| 설문조사 일정 | 다가오는 설문조사 차수 및 마감일 |
| OJT 일지 | 이번 주차 일지 작성 상태 |

우측 메뉴 카드에서 각 기능으로 이동할 수 있습니다.

- **멘토링 프로그램** — 6가지 활동 사진 첨부
- **OJT 일지** — 주차별 업무 일지 작성
- **설문조사** — 차수별 설문 참여
- **공지사항** — 인사팀 공지 확인

## 4. 멘토 등록 요청

담당 멘토를 시스템에 등록하는 절차입니다.

### 등록 방법

1. 메인 대시보드 **"담당 멘토"** 위젯에서 **멘토 등록 요청** 버튼 클릭
2. 멘토 **성명**과 **사번** 입력
   - 사번은 0100을 제외한 고유사번 **6자리**로 입력
3. **등록 요청하기** 버튼 클릭

### 요청 후 상태 확인

| 상태 | 의미 |
|------|------|
| 승인 대기 | 인사팀에서 검토 중 |
| 승인 완료 | 멘토 등록 완료, 멘토가 시스템 접속 가능 |
| 거절 | 인사팀 문의 필요 |

> pending(승인 대기) 상태에서는 수정 및 취소가 가능합니다.

## 5. 멘토링 프로그램 (활동 사진 첨부)

온보딩 기간 중 **6가지 활동**을 수행하고 사진을 첨부하는 기능입니다.

### 6가지 활동 항목

| 번호 | 활동 | 사진 예시 |
|------|------|-----------|
| 1 | 사무실 안내 / PC세팅 | 함께 일할 공간을 둘러보는 사진 등 |
| 2 | 팀원들과 간담회 | 회의 테이블에 모여 있는 사진 등 (얼굴 노출 X) |
| 3 | 구내식당 함께 이용 | 사원증이 보이는 식사 사진 등 |
| 4 | OJT 현황 보고 | 팀원들에게 이번달 배운 업무내용을 공유하는 사진 등 |
| 5 | 협업 부서와 인사 | 사원증이 보이는 커피 사진 등 |
| 6 | 자율활동 | 기타 조직 적응에 도움이 될만한 활동 사진 |

### 사진 첨부 방법

1. 메인 메뉴에서 **멘토링 프로그램** 클릭
2. 완료한 활동 카드 클릭
3. **사진 업로드** 버튼 클릭 → 사진 선택
4. 업로드 완료 시 해당 카드에 사진이 표시됨

> - 사진은 1개 활동당 1장 등록 가능합니다.
> - 새 사진을 업로드하면 기존 사진이 교체됩니다.
> - 6개 활동을 모두 완료하면 진행률 100%가 됩니다.

## 6. OJT 일지 작성

매주 업무 내용을 기록하는 일지입니다.

### 작성 기간

| 구분 | 작성 주차 | 제출 마감 |
|------|-----------|-----------|
| 신입공채 | 1주차 ~ 12주차 | 해당 주 종료일로부터 **3일 이내** |
| 경력공채 | 1주차 ~ 4주차 | 해당 주 종료일로부터 **3일 이내** |

> 마감일이 지난 주차는 잠금 처리되어 작성이 불가합니다.

### 작성 방법

1. 메인 메뉴에서 **OJT 일지** 클릭
2. 작성할 **주차 카드** 클릭
3. 각 항목 작성:
   - **세부 교육 내용**: 평일별로 그날 배운 내용을 작성 (날짜 자동 생성)
   - **어려웠던 점**: 해당 주에 어렵거나 궁금했던 부분
   - **다음 주 목표**: 다음 주에 집중할 내용
4. **임시저장** 또는 **제출하기** 클릭

### 상태 안내

| 상태 | 의미 |
|------|------|
| 기간 전 | 아직 해당 주가 시작되지 않음 |
| 미작성 | 작성 가능한 기간, 작성 전 |
| 작성 중 | 임시저장 상태 |
| 제출 | 멘토에게 제출 완료 |
| 승인 | 멘토가 검토 후 승인 완료 |
| 마감 | 제출 기한 초과 (작성 불가) |

> **임시저장**을 활용하면 작성 중 내용이 저장되어 나중에 이어서 작성할 수 있습니다.
> 제출 후에는 수정이 불가합니다.

## 7. 설문조사

온보딩 과정에 대한 설문조사입니다. 응답 내용은 개인 식별 없이 가공되어 활용됩니다.

### 설문 차수

| 구분 | 설문 차수 | 참여 가능 기간 |
|------|-----------|----------------|
| 신입공채 | 1차, 2차, 3차 | 각 차수 온보딩 기간 종료 후 **7일 이내** |
| 경력공채 | 1차 | 온보딩 기간 종료 후 **7일 이내** |

### 참여 방법

1. 메인 메뉴에서 **설문조사** 클릭
2. **"참여 가능"** 상태의 차수 선택
3. 각 파트별 문항 응답 (객관식, 척도, 주관식)
4. 모든 문항 완료 후 **제출하기** 클릭

### 차수별 상태 안내

| 상태 | 의미 |
|------|------|
| 참여 가능 | 현재 응답 가능한 차수 |
| 기간 전 | 아직 해당 차수 기간이 시작되지 않음 |
| 기간 종료 | 제출 기한 초과 |
| 제출 완료 | 이미 응답 완료 (결과보기 가능) |

> **주의:** 설문은 1회만 제출 가능하며, 제출 후 수정이 불가합니다.
> 마감 기한 내에 꼭 참여해 주세요.

## 9. 전체 일정 흐름 요약

### 신입공채 (12주)

```
입사일
 │
 ├─ [즉시] 로그인 → 비밀번호 변경
 ├─ [즉시] 멘토 등록 요청
 │
 ├─ [1~4주차]  멘토링 프로그램 활동 + OJT 일지 작성
 ├─ [4주차 후] 1차 설문조사 (7일 이내 제출)
 │
 ├─ [5~8주차]  멘토링 프로그램 활동 + OJT 일지 작성
 ├─ [8주차 후] 2차 설문조사 (7일 이내 제출)
 │
 ├─ [9~12주차] 멘토링 프로그램 활동 + OJT 일지 작성
 └─ [12주차 후] 3차 설문조사 (7일 이내 제출)
```

### 경력공채 (4주)

```
입사일
 │
 ├─ [즉시] 로그인 → 비밀번호 변경
 ├─ [즉시] 멘토 등록 요청
 │
 ├─ [1~4주차]  멘토링 프로그램 활동 + OJT 일지 작성
 └─ [4주차 후] 1차 설문조사 (7일 이내 제출)
```
