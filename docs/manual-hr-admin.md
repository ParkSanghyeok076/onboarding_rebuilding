## 1. 로그인 및 화면 구성

### 로그인
HR Admin 계정은 Supabase `users` 테이블에서 `role = 'hr_admin'`으로 지정된 계정입니다. 일반 신입사원과 동일한 로그인 화면을 사용합니다.

### 관리자 화면 구성
로그인 후 왼쪽에 다크 사이드바가 표시됩니다. 사이드바 메뉴:

| 메뉴 | 기능 |
|------|------|
| 📋 멘토링 현황 | 전체 사원 진행률 모니터링 |
| 📝 설문조사 관리 | 설문 응답 조회 및 AI 분석 |
| 📢 공지사항 관리 | 공지 등록·수정·삭제 |
| 👥 신입사원 등록 | CSV 업로드 또는 수동 등록 |
| 🤝 멘토 관리 | 멘토 배정 현황 및 결과요청 메일 |

사이드바 하단에는 현재 로그인한 관리자 이름과 **로그아웃** 버튼이 있습니다.

## 2. 신입사원 등록

신규 입사자 정보를 시스템에 등록합니다. CSV 업로드와 수동 입력 두 가지 방법을 지원합니다.

### 방법 1: CSV 파일 업로드

#### CSV 파일 형식
아래 컬럼명을 정확히 맞춰 작성해야 합니다.

| 컬럼명 | 설명 | 예시 |
|--------|------|------|
| `사번` | 직원 사번 | `1001001` |
| `이름` | 직원 이름 | `홍길동` |
| `부서` | 부서명 | `인사기획팀` |
| `입사일` | YYYY-MM-DD 형식 | `2026-03-17` |
| `구분` | `신입` 또는 `경력` | `신입` |

> 입사일은 반드시 **YYYY-MM-DD** 형식이어야 합니다.
> 구분은 **신입** 또는 **경력** 두 값만 허용됩니다.

#### 업로드 절차
1. 사이드바에서 **신입사원 등록** 메뉴를 클릭합니다.
2. 파일 업로드 영역에 CSV 파일을 **드래그&드롭** 하거나 클릭해 선택합니다.
3. 미리보기 테이블에서 데이터를 확인합니다.
4. 형식 오류가 있으면 상단에 오류 메시지와 대상 사번이 표시됩니다. CSV 파일을 수정 후 재업로드 하세요.
5. **등록하기** 버튼을 클릭하면 등록이 완료됩니다.

> 중복 사번이 있으면 등록이 차단됩니다. 오류 메시지를 확인하고 수정하세요.

### 방법 2: 수동 직접 입력

1. CSV 업로드 영역 아래 **수동 입력 테이블**을 사용합니다.
2. 각 행에 사번, 이름, 부서, 입사일, 구분을 입력합니다.
3. 행을 추가하려면 **+ 행 추가** 버튼을 클릭합니다.
4. **등록하기** 버튼으로 저장합니다.

### 등록 후 자동 처리 사항
- 초기 비밀번호가 자동 생성됩니다: `y사번` (예: `y1001001`)
- 신입 사원의 설문 기간이 입사일 기준으로 자동 계산됩니다.
  - 1차: 입사일 ~ 입사일 +28일
  - 2차: 입사일 +29일 ~ +56일 (신입만)
  - 3차: 입사일 +57일 ~ +84일 (신입만)

## 3. 멘토링 현황

전체 신입사원의 멘토링 진행 상황을 한눈에 파악할 수 있습니다.

### KPI 카드

화면 상단에 4개의 KPI 카드가 표시됩니다.

| 카드 | 내용 |
|------|------|
| 전체 입사자 | 등록된 총 사원 수 |
| 온보딩 완료 | 진행률 100% 달성 인원 |
| 이번주 설문 마감 | 이번 주 내 설문 마감 예정 인원 |
| 마감 임박자 | 3일 이내 설문 마감 예정 인원 |

- **이번주 설문 마감** 카드(노란색)를 클릭하면 해당 인원 목록(이름·팀·차수·마감일·완료여부)이 팝업으로 표시됩니다.
- **마감 임박자** 카드(빨간색)를 클릭하면 긴급 대응 대상자 목록이 팝업으로 표시됩니다.

### 현황 테이블

| 컬럼 | 내용 |
|------|------|
| 이름 | 사원 이름 |
| 부서 | 소속 부서 |
| 구분 | 신입 / 경력 |
| 입사일 | 입사 날짜 |
| 멘토 ID | 사원이 직접 입력한 멘토 사번 |
| 1차 / 2차 / 3차 기간 | 각 설문 응답 기간 |
| 진행률 | 컬러 프로그레스 바 + % 수치 |

- 각 컬럼 헤더를 클릭하면 **오름차순/내림차순 정렬**이 됩니다.
- **이름 검색** 필터로 특정 사원을 빠르게 찾을 수 있습니다.

#### 진행률 계산 기준

| 항목 | 신입 (최대 10점) | 경력 (최대 8점) |
|------|------|------|
| 멘토링 프로그램 6가지 | 6점 | 6점 |
| OJT 계획 수령 | 1점 | 1점 |
| 설문 완료 | 최대 3점 (1·2·3차) | 최대 1점 (1차) |

## 4. 설문조사 관리

신입사원이 제출한 설문 응답을 조회하고, AI 분석 및 피드백 메일 초안을 생성할 수 있습니다.

### 설문 목록 조회
1. 사이드바에서 **설문조사 관리** 메뉴를 클릭합니다.
2. **차수 필터** (전체/1차/2차/3차)와 **이름 검색**으로 원하는 응답을 찾습니다.
3. 응답 행을 클릭하면 해당 사원의 설문 상세 답변 팝업이 열립니다.

### AI 분석 (ABSA)

주관식 응답 7개 항목을 AI가 **속성 기반 감성 분석**합니다.

1. 설문 응답 목록에서 분석할 행의 **분석 실행** 버튼을 클릭합니다.
2. AI가 응답 내용에서 핵심 속성(예: "소통 빈도", "업무 피드백")과 감성(긍정·부정·중립)을 추출합니다.
3. 분석 완료 후 **분석 결과 보기** 버튼이 활성화됩니다. 클릭하면 결과 팝업이 열립니다.
4. 분석 결과에는 다음 정보가 포함됩니다:
   - 속성명 (텍스트에서 추출된 실제 개념)
   - 감성 (긍정 / 약간긍정 / 중립 / 약간부정 / 부정)
   - 감성 점수 (-1.0 ~ +1.0)
   - 신뢰도 (높음 / 보통 / 낮음)
   - 원문 발췌 근거

> 한번 분석된 응답은 중복 분석되지 않습니다.

#### AI 분석 활용 권고
- 감성 **점수의 절대값보다 방향성**을 위주로 해석하세요.
- 짧거나 무성의한 응답의 분석 결과는 참고만 하세요.
- 분석 결과 단독으로 인사 판단을 내리지 말고, 담당자의 정성적 검토와 병행하세요.

### 객관식 시계열 분석

3차 설문을 모두 완료한 신입사원에 한해 **차수별 점수 추이 분석**이 가능합니다.

1. 해당 사원의 행에서 **추이 분석** 버튼을 클릭합니다.
2. Part 1~4 파트별 평균 점수가 꺾은선 그래프로 표시됩니다.
3. AI 요약 코멘트도 함께 제공됩니다.

### 피드백 메일 초안 생성

AI 분석 결과를 바탕으로 멘토 또는 팀장에게 보낼 피드백 메일 초안을 자동 생성합니다.

1. 분석이 완료된 응답에서 **메일 초안 생성** 버튼을 클릭합니다.
2. **멘토용**과 **팀장용** 두 가지 초안이 생성됩니다.
3. 초안을 확인하고 필요 시 내용을 수정한 뒤 발송합니다.

> 메일 초안은 시스템에서 **직접 발송하지 않습니다.** 초안을 복사해 이메일 클라이언트에서 직접 발송하세요.

## 5. 공지사항 관리

신입사원이 볼 공지사항을 등록·수정·삭제합니다.

### 공지 등록
1. 사이드바에서 **공지사항 관리** 메뉴를 클릭합니다.
2. **새 공지 등록** 버튼을 클릭하면 작성 폼이 열립니다.
3. 제목과 본문을 입력합니다.
4. 상단 고정이 필요한 공지는 **고정 공지** 체크박스를 선택합니다.
5. PDF 파일이 있으면 **파일 첨부** 영역에서 선택합니다.
6. **등록하기** 버튼으로 저장합니다.

### 공지 수정
1. 목록에서 수정할 공지를 클릭합니다.
2. 상세 화면에서 **수정** 버튼을 클릭합니다.
3. 제목·본문·고정여부·PDF를 변경할 수 있습니다.
   - 기존 PDF를 삭제하려면 **PDF 삭제** 체크박스를 선택합니다.
   - 새 PDF로 교체하려면 새 파일을 첨부합니다.
4. **저장** 버튼으로 완료합니다.

### 공지 삭제
1. 상세 화면에서 **삭제** 버튼을 클릭합니다.
2. 확인 팝업에서 **삭제** 를 누르면 영구 삭제됩니다.

> 고정 공지(📌)는 신입사원 화면에서 항상 목록 상단에 표시됩니다.

## 6. 멘토 관리

멘토 배정 현황을 확인하고, 멘토링 결과 보고 요청 메일을 생성합니다.

### 멘토 배정 현황 테이블

| 컬럼 | 내용 |
|------|------|
| 이름 | 신입사원 이름 |
| 부서 | 소속 부서 |
| 구분 | 신입 / 경력 |
| 입사일 | 입사 날짜 |
| 멘토 ID | 신입사원이 직접 입력한 멘토 사번 |
| 결과요청 | 결과요청 메일 생성 버튼 |

> 신입사원이 멘토 정보를 아직 입력하지 않은 경우 멘토 ID 열이 비어있습니다.

### 결과요청 메일 생성

멘토링 종료 후 멘토에게 보내는 결과 보고 요청 메일 초안을 생성합니다.

1. 해당 신입사원 행의 **메일 생성** 버튼을 클릭합니다.
2. 미리보기 팝업에서 메일 내용을 확인합니다.
3. **클립보드 복사** 버튼으로 메일 내용을 복사한 뒤 이메일 클라이언트에 붙여넣어 발송합니다.

> 메일은 시스템에서 직접 발송되지 않습니다. 복사 후 직접 발송해 주세요.

### 신입사원 일괄 메일 생성

**신입사원 일괄 메일** 기능으로 다수의 신입사원을 대상으로 한 안내 메일을 일괄 생성할 수 있습니다.

1. 메일 대상자를 선택합니다.
2. 메일 내용을 확인하고 복사합니다.

## 7. 자주 묻는 질문

**Q. 신입사원이 비밀번호를 잊어버렸어요.**
A. Supabase 대시보드에서 해당 사원의 비밀번호를 초기화할 수 있습니다. 또는 계정을 삭제 후 재등록하면 초기 비밀번호(`y사번`)로 초기화됩니다.

**Q. CSV 업로드 시 오류가 발생해요.**
A. 오류 메시지에서 문제 사번을 확인하세요. 주요 원인:
- 입사일이 `YYYY-MM-DD` 형식이 아닌 경우
- 구분이 `신입` 또는 `경력` 이외의 값인 경우
- 사번이 CSV 내에서 중복된 경우
- 이미 시스템에 등록된 사번인 경우

**Q. AI 분석 버튼이 안 보여요.**
A. 해당 응답이 이미 분석된 경우 분석 버튼 대신 **분석 결과 보기** 버튼이 표시됩니다.

**Q. 객관식 시계열 분석이 안 되는 사원이 있어요.**
A. 시계열 분석은 1차·2차·3차 설문을 모두 완료한 **신입사원**에게만 제공됩니다.

**Q. 공지사항 PDF가 업로드 안 돼요.**
A. PDF 형식(.pdf) 파일만 첨부 가능합니다. 파일 크기가 너무 큰 경우 Supabase Storage 용량 제한을 확인해 주세요.

**Q. 진행률이 이상해요.**
A. 진행률은 멘토링 프로그램 완료(최대 6점), OJT 계획 수령(1점), 설문 완료(신입 최대 3점, 경력 1점) 기준으로 계산됩니다. 신입 기준 최대 10점, 경력 기준 최대 8점입니다.
